方法论

  1. 智能指数 I：Terminal-Bench 4.0（终端代理编程）、Humanity's Last Exam（综合推理）与 AutomationBench（SaaS 工作流自动化）三项得分的算术平均，全部由 Artificial Analysis 以统一口径独立实测，非厂商自报。
  2. 速度 S 与 Token 消耗 N：均为 AA 实测。S 为输出速度（tokens/s）；N 为三项基准每任务输出 Token（含推理）的平均值，话痨模型的真实成本会被如实计入。
  3. 智能密度 D = I/100 × S：每秒产出的“质量加权 Token”数，衡量智能产出速率。
  4. 每元智能 V = I ÷ (N/1M × 输出单价)：在典型基准任务上，一元钱（或一美元）能买到的智能分。速度不计入 V，由 D 单独体现。
  5. 双币种：有官方双币定价的模型（DeepSeek、Kimi、Qwen、GLM、Mimo）按各自官方价独立计算；仅美元定价的模型按 1 USD = 7.2 CNY 换算。
  6. 排序：默认为本页语言对应币种的每元智能降序，点击表头可按其他指标重排。

常见问题

智能指数和每元智能是怎么计算的？
智能指数是 Terminal-Bench 4.0、Humanity's Last Exam、AutomationBench 三项独立实测得分的平均值。每元智能 = 智能指数 ÷ 每任务成本，其中每任务成本 = 实测的每任务输出 Token 数 × 模型输出单价——因此话痨模型即使单价低，也可能因 Token 消耗大而性价比变低。
数据来源是什么，可靠吗？
能力、速度与 Token 消耗均来自 Artificial Analysis 的独立实测（统一基准环境，非厂商自报）；价格取自各厂商官方 API 定价页。例如 Claude Sonnet 5.5 在 HLE 上的实测得分 55.0% 与 Anthropic 官方公布的 54.9% 基本一致。
为什么速度快的模型性价比不一定高？
每元智能只衡量“花一元钱买到多少智能”，速度由智能密度（D = 智能指数/100 × 速度）单独体现。例如 Gemini 3.8 Flash 智能密度第一，但 Token 消耗较高使其性价比位于中游。在意吞吐看智能密度列，在意成本看每元智能列。
